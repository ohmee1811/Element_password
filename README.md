# 🧪 Element Cipher

### A Cipher Using the First 100 Chemical Elements

**Element Cipher** is a custom encoding system that uses the chemical symbols of the first 100 elements in the periodic table.

Instead of representing information with ordinary letters or numbers, Element Cipher uses chemical element symbols.

## 🌟 Features

* 🧪 **100 Elements** — Uses elements 1–100, from Hydrogen (H) to Fermium (Fm).
* 🔐 **Custom Encoding** — Represents information using chemical symbols.
* 🔓 **Decoding** — Converts encoded element symbols back into their original information.
* ⚡ **Simple & Creative** — Combines chemistry, mathematics, and computer science.

## 🔐 How It Works

Element Cipher uses chemical element symbols to encode information.

### Encoding

1. Enter the original message.
2. Convert the message using the Element Cipher encoding rules.
3. Get an encoded message containing chemical element symbols.

### Decoding

1. Enter an encoded message.
2. Identify the chemical element symbols.
3. Apply the decoding rules.
4. Recover the original message.
